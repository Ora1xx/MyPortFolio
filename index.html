P.01

Virtual Gaming Steering

IN DEVELOPMENT

Overview

VGS turns an Android smartphone into a wireless steering controller for PC racing games without proprietary hardware. Motion sensor data is relayed over UDP to a PC receiver, which maps it to a virtual controller that the game recognises.

Problem

PC racing games expect a dedicated steering wheel peripheral. Physical controllers are expensive. The aim is to use hardware most people already own — a modern Android phone — and bridge the gap entirely in software.

System Architecture

  1. Android app reads gyroscope and accelerometer input
  2. Sensor data is serialised and sent via UDP over a local network
  3. Python receiver on the PC parses incoming packets
  4. Virtual controller is instantiated (e.g. via vgamepad)
  5. Axis and button mappings are applied and fed to the game

Technologies

  • Kotlin
  • Android SDK
  • UDP Sockets
  • Python
  • vgamepad
  • LAN Networking
  • Sensor API

Implementation Status

Active development. Core UDP transmission and receiver architecture are being prototyped. Virtual controller mapping and latency optimisation are the next milestones.

Challenges & Lessons

Sensor noise filtering, UDP packet-loss tolerance and platform-specific virtual input driver requirements are the primary technical challenges. Each constraint is shaping a more robust architecture than the initial design.
